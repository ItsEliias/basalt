# V3.3 report — UI actions pass

Branch `v3-3-actions` · 2026-09-04 · suite green at every commit (871 tests
— +2: the theme-bypass guard and the water-tile pin). Findings came from the
committed V3.2 README screenshots; before/after crops for each surface are
in `docs/report-assets/v3.3/`.

## The eleven items

1. **Theme-bypass sweep** — ~400 `color.*` imports of the static Minimal
   palette across 36 files (every screen, six shared ui components) now
   route through `useTheme()`. This was the batch's real bug: five of the
   six themes were rendering Minimal's colours on every bypassed surface —
   unreadable light-on-paper rows on Humanist/Brutalist, dead accents
   everywhere. Sleep-stage fills derive per theme (`sleepStagePalette`);
   `themeBypass.test.ts` walks both source trees and fails on any static
   `color` import outside the theme system, closing the gap the
   conformance suite couldn't see (it proves themes are sound, not used).
2. **Set completion** — each set row has a 48dp ✓ checkbox column: tap to
   commit, tap to reopen. Keyboard-dismiss commit stays as the secondary
   path. Completion itself is still typographic.
3. **Train hierarchy** — Add set is a real bordered 48dp button per
   exercise; End session moved to a compact header action confirmed by the
   RPE bottom sheet (which gained "cancel — keep training"); Add exercise
   dropped to secondary weight; Adapt is a Chip. `CTA` grew a `secondary`
   variant and a 48dp min-height.
4. **Tray commit bar** — bottom-anchored above the tab bar: running total
   left, "Log N items" as a filled mark/markOn button, Clear as text.
   LOG ALL is gone from the top banner (the banner is gone entirely).
5. **Capture modes** — SEARCH/BARCODE/PHOTO/AI/MANUAL are a 44dp
   segmented control at the bottom of the capture area, active segment
   filled — unmistakable for the tab-level sub-nav now.
6. **Start walk** — pinned bar above the tab bar (GPS accuracy + filled
   CTA); weather, guided scripts, shoes and loops scroll behind it.
7. **Quick log +** — 56dp, filled `fill.mark`/`fill.markOn` in every theme
   (contrast pinned by conformance), raised above the bar line.
8. **Fine print folds** — SrcNote self-measures: past two lines it shows
   its first line + a why→ disclosure, expanding in place. The Trends
   checked-not-shown list folds to "N pairs checked · none past
   |r| ≥ 0.45 · show list" and expands in place with the r values.
9. **Controls look like controls** — Settings Today-section rows are real
   Switches (ReceiptRow grew a `right` slot); Recover's TRACK CYCLE
   micro-label is a secondary button with its opt-in line kept beneath.
10. **Water tile** — zero logged reads "Nothing logged yet · 3,000 ml"
    (target stated), never a placeholder 0. Pinned by a tile-spec test.
11. **Guided timer** — the countdown renders at 104 while counting (64
    idle) and the phase label steps up; macro/cap ratio lines floor at
    `max(12.5, scale.sm)` in the theme's data face — Athletic's condensed
    face cramped at the old fixed 12.
