What changes in the contract

Forbidden list becomes two lists. Globally forbidden stays: XP, confetti, streak shaming, fake precision, narration of results, hidden formulas. Theme-scoped expression is new: rings, gradients, glow, soft shadow, tilt, pastel grounds — each gated by a token, each allowed only where a theme declares it. Minimal declares none of them, so the default app is untouched.

Ring rule. meter: 'ring' is legal, but a ring can only show 100%. Over-cap must also render in words next to the ring. That's a conformance test, not a guideline.

Pebble rule. Pebble may only render when a proposal with an action exists. No proposal, no Pebble. Off, every message ships in Basalt's plain voice with identical actions — the mascot is a voice setting, never a content setting.
